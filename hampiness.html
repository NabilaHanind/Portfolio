Hampiness: Hampers Ordering Information System

A comprehensive information system and mobile application designed to streamline hampers ordering, vendor product management, and business report generation using a 3-tier architecture.

Role: System Analyst & UI Designer
Timeline: 2025
Team: 4 Members
View Full PDF Report View Figma UI

1. Project Overview & Challenge

Hampiness was developed to solve operational inefficiencies in traditional hampers ordering processes. Vendors often experienced delays in order notifications, manual product inputs, and unstructured tracking, while customers faced difficulties in scheduling deliveries and personalizing items.

2. System Analysis & UML Modeling

Using system analysis frameworks, we diagnosed operational bottlenecks via Fishbone Diagrams and mapped out data flows, context diagrams, DFD Level 0, Use Case diagrams, and Class Diagrams to ensure a robust system foundation.

The customer-facing mobile application features seamless registration, category exploration, custom hampers ordering, flexible delivery scheduling, and secure payment processing.
